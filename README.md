# cbpi4-HeatStep

Простой плагин шага Heat для CraftBeerPi 4.

## Описание

Минималистичный шаг для задания целевой температуры котла и включения его нагрева. Плагин устанавливает уставку, активирует встроенную логику котла (PID или гистерезис) и сразу завершается, позволяя нагреву работать независимо от дальнейшего выполнения рецепта.

Идеально подходит для сценариев, когда нужно начать нагрев одного котла параллельно с другими процессами (например, нагрев промывочной воды в бойлере во время затирания).

## Возможности

- **Задание уставки**: Установка целевой температуры для выбранного котла
- **Автоматический запуск нагрева**: Включение режима AutoMode котла при старте шага
- **Мгновенное завершение**: Шаг сразу переходит к следующему, не блокируя рецепт
- **Независимая работа**: Нагрев продолжается через встроенную логику котла (PID/гистерезис) до ручной остановки
- **Изоляция котлов**: Управление только выбранным котлом, остальные остаются нетронутыми
- **Безопасная остановка**: При ручной остановке рецепта нагрев автоматически выключается

## Параметры шага

- **Kettle** (Котел): Выберите котел для управления. Уставка и AutoMode будут применены только к этому котлу.
- **Target Temp** (Целевая температура): Температура (°C), до которой должен греться котел.
