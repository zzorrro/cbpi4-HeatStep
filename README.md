# cbpi4-HeatStep

Простой плагин шага Heat для CraftBeerPi 4.

## Описание

Шаг для установки целевой температуры котла и включения его нагрева. Плагин устанавливает уставку, активирует встроенную логику котла (PID или гистерезис), включает нагрев и завершается, позволяя основному рецепту продолжаться. 

Нагрев работает независимо в фоновом режиме. Для безопасности реализован **автоматический таймаут**: нагрев будет принудительно выключен через заданное время, даже если вы забыли сделать это вручную или рецепт уже перешел к другим этапам.

Идеально подходит для сценариев, когда нужно начать нагрев одного котла параллельно с другими процессами (например, нагрев промывочной воды в бойлере во время затирания).

## Возможности

- **Задание уставки**: Установка целевой температуры для выбранного котла.
- **Автоматический запуск нагрева**: Включение режима AutoMode котла при старте шага.
- **Мгновенное завершение**: Шаг отрабатывает за 1 секунду и переходит к следующему, не блокируя рецепт.
- **Изоляция котлов**: Управление только выбранным котлом, остальные остаются нетронутыми.
- **Автоматическая защита**: Задача максимального времени работы (по умолчанию 90 минут с момента старта).

## Внимание!

- Запуск шага происходит автоматически. Убедитесь, что котел заполнен до старта шага!
- Нельзя использовать для выбранного котла ту же логику нагрева, что и для основного котла.

## Параметры шага

- **Kettle** (Котел): Выберите котел для управления. Уставка и AutoMode будут применены только к нему.
- **Target Temp** (Целевая температура): Температура (°C), до которой должен греться котел.
- **Safety Timeout** (Время безопасности): Автоматическое отключение нагрева через N минут. **По умолчанию: 60**. Установите `0`, чтобы отключить эту функцию и греть до ручной остановки.
